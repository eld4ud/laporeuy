# LaporWud

Overlay Laravel untuk sistem pelaporan kerusakan fasilitas sekolah.

## Fitur
- Landing page bergaya dark editorial.
- Login terpisah untuk pelapor, admin, dan teknisi.
- Role siswa, guru, admin, teknisi.
- Pelapor membuat laporan dengan validasi foto.
- Admin memverifikasi laporan, menugaskan teknisi, dan menyetujui bukti perbaikan.
- Teknisi melihat tugas miliknya, memperbarui progres, dan mengunggah bukti.
- Filter laporan admin berdasarkan status dan tanggal.
- Riwayat perubahan status.

Lihat `LAPORWUD-INSTALL.txt` untuk instalasi.
